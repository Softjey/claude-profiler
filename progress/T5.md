Notes:
- FR6 ("Model span = timestamp(assistant) − timestamp(previous timestamped event)") is implemented against a session-wide sorted set of all timestamped points visible to the metrics layer (assistant/user_prompt/system event timestamps, plus each tool_use's start and, when matched, its end) — the metrics layer only receives `EventModel`, not raw transcript records, per the `metrics ← model ← parse` layering, so raw `tool_result` timestamps are represented only via `ToolUseEvent.durationMs`.
- Buckets are made mutually exclusive by subtraction in priority order tools → model → user (`subtractIntervals` in `src/metrics/interval.ts`), per FR8/D12, before computing the residual — this makes the sum-to-span invariant hold by construction rather than by chance.
