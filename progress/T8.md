Notes:

- **The tool name is "Agent", not "Task", in every real transcript on this machine.**
  Neither `plan.md` nor `SPEC.md` name it explicitly as a fork/version difference, but a
  corpus-wide grep (`grep -rl '"name":"Task"' ~/.claude/projects`) returns zero hits across
  the whole local corpus, while `"name":"Agent"` is what actually spawns every one of the
  297 local `agent-*.jsonl` files. `resolve-subagents.ts` treats both `"Task"` and `"Agent"`
  as subagent-spawning tool names (`SUBAGENT_TOOL_NAMES`) so the matcher works against both
  the vanilla CLI's naming and this environment's. `tool-stats.ts`'s `classifyKind` (T6, out
  of scope for T8) still only recognizes `"Task"` for the `kind: "task"` label — wiring
  `ToolCall.subagentRef` onto the tool table is T11/T14's job, not T8's.
- **Matching strategy differs from `plan.md`'s literal wording, for a reason discovered
  empirically.** The plan describes two methods (tool-result agent id, then time
  containment). All 297 local `agent-*.jsonl` files carry a sibling `agent-<id>.meta.json`
  with an exact `toolUseId` field — a more reliable signal than either method the plan
  named, present on 100% of the corpus (verified by script, not sampling). Implemented as
  the first-priority match (`matchMethod: "meta"`, confidence `"exact"`), with the plan's
  two methods kept as fallbacks (`"tool-result-id"` / `"time-containment"`) for older
  transcripts that might lack the sidecar file (FR2: schema drift across CC versions).
  All three are exercised by `resolve-subagents.test.ts` against hand-built fixtures, since
  the local corpus alone doesn't exercise the fallback paths (every real file has the
  sidecar).
- Ambiguity handling: time-containment only accepts a call span when exactly one unmatched
  candidate call contains the agent's own record span; two or more fitting candidates leave
  both unmatched rather than guessing.
- `SubagentStat` (per `SPEC.md`'s Data model) has no cost field — subagent transcripts never
  carry `cost-state` (FR14), so cost is omitted rather than a fabricated `null`.
- Files touched: `src/model/resolve-subagents.ts`, `src/metrics/subagent-stats.ts` (both new),
  plus `src/model/resolve-subagents.test.ts` and `src/metrics/subagent-stats.test.ts`. No
  existing file was modified.
